# Slip

A daily word puzzle. Slide the rows and columns of a 4×4 letter grid until the four rows spell four hidden words, in any order. Static site: plain HTML, CSS and JavaScript, no build step, no server.

## How to play

- Tap an arrow to slide a row left or right, or a column up or down. You can also swipe a tile.
- Letters that slide off one edge come back on the other.
- A row slide only reorders that row. A column slide carries letters between words, so fixing one row can break another.
- Nothing is marked while you slide. Check (three per puzzle) shows which rows currently spell a hidden word.
- Par is the fewest moves possible. The share text shows your moves against par.
- Undo and Reset are free. Give up reveals the words and counts as a loss.

Other real words built from the same letters count too. For example BARE counts as BEAR. The `alts` list in each puzzle holds these.

## Files

| File | Purpose |
|---|---|
| `index.html` | The game screen. |
| `core.js` | Grid moves, win check, exact solver, scrambler, stats, share text. |
| `data.js` | The puzzles. Generated by `make-puzzles.js`. |
| `make-puzzles.js` | Scrambles each word set, solves it exactly, writes `data.js`. |
| `test.js` | Logic tests. |
| `smoke.js` | Runs the game screen against a fake DOM. |
| `manifest.webmanifest`, `sw.js`, `icon-*.png` | Add to Home Screen and offline play. |

## Commands

```text
node test.js        # 22 logic tests, including a fresh exact-par search for every puzzle
node smoke.js       # screen checks: no marks before Check, swipes, win, give up, bad saves
node make-puzzles.js  # rebuild data.js from the word sets
```

## Add puzzles

1. Add a set of four 4-letter words to `WORD_SETS` in `make-puzzles.js`.
2. If any word has an anagram that is also a real word, add it to `ALTS` so players are not marked wrong for it.
3. Run `node make-puzzles.js`, then `node test.js`.

Every puzzle is built by sliding the solved grid, so it is always solvable. The maker rejects scrambles that start with a correct row or have a par outside 4 to 7.

## Daily puzzle

`Core.dayIndex()` counts local days since 2026-01-01 and picks `PUZZLES[dayIndex % PUZZLES.length]`. Everyone gets the same puzzle each day with no backend.

## Run locally

Open `index.html`, or run `python3 -m http.server` in the folder.

## Publish on GitHub Pages

1. Create a new public repository, for example `slip`.
2. Upload every file in this folder to the top level of the repository.
3. In Settings → Pages, choose Deploy from a branch, branch `main`, folder `/ (root)`, and save.
4. Open `https://<username>.github.io/slip/` after a minute or two.

## Storage

Progress and stats are kept in the browser's local storage on that device. They do not sync. A saved game from another day, another puzzle or with altered letters is discarded.

## Known limits

- 14 puzzles, so they repeat every 14 days.
- A word set can sometimes be rebuilt into other real words that are not in `alts`. The grid has 16 letters, so some combinations are possible. If a player reports one, add it to `ALTS` and rebuild.
